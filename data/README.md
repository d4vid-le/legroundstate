# Data

This directory is **gitignored** except for this README. Datasets are large and have
per-source licenses; they are not committed.

## Policy

- Every board has a manifest entry: source, license, author/project, URL, commit, SHA-256.
- Training data must be DRC-verified. A route that does not pass `kicad-cli pcb drc` is not
  a positive label.
- The QT Py ESP32-S2 board is **held out**; it must not appear in any training shard.
- Synthetic data is generated by our own scripts and is owned by the project.
- Human labels are stored in SQLite, exported as immutable JSONL with a manifest hash; see
  `docs/LABELING.md`.
- PCBench/PCBWorld boards retain their original licenses; only permissively licensed boards
  may be included in a released dataset.
- Do not commit datasets. Publish them via a release or Hugging Face dataset with a data card.

## Collection sources

| Source | How | License check |
|---|---|---|
| Synthetic generator | `src/legroundstate/data/synthetic.py` (Phase 1) | Ours |
| QT Py snapshot | `boards/qt-py-esp32-s2/` | CC BY-SA 3.0; held out |
| PCBench | GitHub release / `tools/prepare_pcbench.sh` | Per-board; record in manifest |
| PCBWorld D3 | `tools/quickstart/prepare_pcbench.sh` | Code BSD-3; boards per-project |
| Open hardware (Adafruit, SparkFun, KiCad demos) | Manual download; record URL + commit | Only MIT / Apache-2.0 / CC BY / CC BY-SA / CERN-OHL |
| User's own boards | Local | User-owned; ask before training |

**Do not scrape proprietary boards or boards with no license.** When in doubt, exclude the
board from training and use it only for local evaluation, or skip it.

## Layout (planned)

```
data/
  raw/            fetched source boards (gitignored)
  synthetic/      generated boards + labels
  l0/             L0 tensor shards + manifest.jsonl
  l1/             L1 per-net shards
  labels/         exported human labels (append-only, versioned)
  eval/           frozen benchmark sets (B0–B4)
  manifests/      license/provenance records
```
